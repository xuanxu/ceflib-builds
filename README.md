# CEFLIB builds

Builds for the [CEFLIB library](http://ceflib.irap.omp.eu/), a tool used to read efficiently Ascii files in CEF format.

The Cluster Exchange Format (CEF) has been defined by ESA for the needs of the Cluster Active Archive (CAA).

Find compiled libraries in the [PYTHON/builds dir](https://github.com/xuanxu/ceflib-builds/tree/main/codebase/PYTHON/builds).
